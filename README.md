# SI Estrategia - sitio web inicial

Primera versión estática y responsive para GitHub Pages.

## Archivos
- `index.html`: contenido de la web.
- `styles.css`: diseño, paleta y responsive.
- `assets/logo-si-estrategia.png`: logo usado en esta versión.

## Antes de publicar
1. Reemplazar `contacto@siestrategia.cl` si el correo definitivo es otro.
2. Confirmar que el logo final tenga fondo transparente si se quiere una integración más limpia.
3. Revisar textos finales de servicios.
4. Si compran `siestrategia.cl`, agregar un archivo `CNAME` con ese dominio una vez configurado GitHub Pages.

## Publicar en GitHub Pages
1. Crear un repositorio público en GitHub.
2. Subir estos archivos a la raíz del repositorio.
3. Ir a `Settings > Pages`.
4. En `Build and deployment`, elegir `Deploy from a branch`.
5. Seleccionar `main` y carpeta `/ (root)`.
6. Guardar y esperar la publicación.
